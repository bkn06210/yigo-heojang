### 1) 경로 오류 — 확인 결과

멤버십 추가 화면은 라우터상 `/memberships/register`로, **혜택 탭의 [+추가]**에서 들어갑니다.
설정에는 없습니다. 설정에 있는 건 `/settings/personalization`(개인화 설정)이고,
**검색 로직은 두 화면이 동일**하므로 어느 쪽에서 찍어도 기능 시연은 같습니다.

→ **혜택 탭 쪽을 택했습니다.** ⑥ 혜택 통합 조회와 한 번의 이동으로 묶여서 **시간이 절약**됩니다.

### 2) 타이밍 — v4 표의 숫자가 맞지 않았습니다

**① 표 내부 불일치**
A-2 헤더는 `2분 25초`인데 소섹션을 더하면 `10+35+35+15+25+5 = 2분 5초`입니다. 20초 차이.

**② 실제 낭독 시간이 표기보다 깁니다**
내레이션 글자 수를 발표 속도(약 4.8자/초)로 환산한 결과:

| 섹션 | v4 표기 | 실측 낭독 | 차이 |
|---|---|---|---|
| ② 홈 — 두리 브리핑 | 35초 | **39초** | +4 |
| ③ 결제 | 35초 | **53초** | **+18** |
| ④ 검색 | 15초 | **27초** | **+12** |
| ⑤ 챗봇 | 25초 | 21초 | −4 |
| 핵심 설계(AI 분리) | 20초 | **30초** | **+10** |

v4를 그대로 읽으면 **총 5분 16초 + 정지 7.5초 ≈ 5분 25초**로 **가이드 상한을 넘습니다.**

→ v5는 **문장을 줄여** 실측 기준 **4분 35초**에 맞췄습니다. 내용은 하나도 안 뺐습니다.
